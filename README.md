A Leonida Air boarding pass for the flight that waited 13 years: two loop-de-loop delays, 4,811 days delayed, 214 GB of baggage, and a fare paid by the author's AI agent on make.fun. Drawn from scratch in Pillow.

## Post the meme

Attach meme.png as the first image of a public X post, paste the text block from CAPTION.md as the post text, copy the published post URL into the url field of POST.json, and keep the post public until results are out.

## Reproduce locally

Run `python3 gen-meme.py` with Pillow and the Noto fonts installed. Test the entrypoint with `MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts`. The checked-in POST.json intentionally retains its starter placeholder until the public X post exists.
